# 0.10.0 Plan 02 — D1: Unified Engine Acquisition (`admina/engines`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One engine-acquisition point for firewall / PII / loop breaker — Rust auto-detection, `ADMINA_ENGINE` override, and admina.yaml firewall overrides reach **every** surface (proxy, SDK, integrations), killing the `cfg.raw` dead code and the proxy-private bridge.

**Architecture:** Move `proxy/engine_bridge.py` to a new `admina/engines/` package that sits beside `admina/domains` in the dependency graph (imports only core + domains, never proxy). The proxy module becomes a re-export shim; `integrations/_engines.py` and the five SDK `_load_*` helpers delegate. Firewall YAML overrides move to **typed** config fields (root fix for the `cfg.raw` bug). The `cfg.pii_engine` resolver seam lands here (only `spacy-regex` wired; Plan 04 adds `presidio`).

**Tech Stack:** Python 3.11, pytest (`.venv/bin/python -m pytest`), optional `admina_core` (Rust) guarded by `importorskip`.

**Branch:** `release/0.10.0`. Commit per task; NEVER tag; do not push.

**Audit findings absorbed:** `engine_bridge.py:124` (Rust `get_stats()` keys not normalized → Prometheus silently wrong). **Out of scope (tracked Rust-parity workstream):** Rust algorithm differences (loop_breaker.rs TF-IDF, pii.rs EU-ID coverage, firewall homoglyph subset).

**Behavior changes (deliberate, pre-1.0, CHANGELOG'd in Plan 07):** SDK primitives and LangChain/CrewAI callbacks gain Rust acceleration (when installed), admina.yaml firewall overrides, and `pii_engine` selection — previously proxy-only.

```python
def _resolve_engine() -> str:
    """Effective engine: ADMINA_ENGINE env override, else auto-detect."""
    mode = os.environ.get("ADMINA_ENGINE", "auto").lower()
    if mode not in ("auto", "python", "rust"):
        raise ValueError(
            f"ADMINA_ENGINE must be auto|python|rust, got {mode!r}"
        )
    if mode == "rust" and not _rust_available:
        logger.warning(
            "ADMINA_ENGINE=rust but admina-core is not installed — "
            "falling back to python (pip install 'admina-framework[rust]')"
        )
        return "python"
    if mode == "auto":
        return "rust" if _rust_available else "python"
    return mode
```

```python
def get_pii_engine(name: str | None = None) -> PIIBridge:
    """Get the configured PII engine.

    Resolution: explicit *name* arg > admina.yaml ``pii_engine`` >
    ``spacy-regex``. An engine selected by name takes precedence over
    Rust auto-detection (Rust accelerates only the spacy-regex path).
    """
    if name is None:
        try:
            from admina.core.config import load_config

            name = load_config().pii_engine
        except (ImportError, ValueError, OSError):
            name = "spacy-regex"
    factory = _PII_ENGINE_FACTORIES.get(name)
    if factory is None:
        raise ValueError(
            f"Unknown pii_engine {name!r}. Available: "
            f"{sorted(_PII_ENGINE_FACTORIES)}. 'presidio' requires "
            f"admina-framework[presidio] (0.10+)."
        )
    return factory()
```
