**Goal:** Bring the three SDK governed primitives into line with the canonical pipeline and close their audit findings: GovernedModel gains full protection (firewall + PII + optional loop + guards) ON by default (finding I — the brainstorm-approved behavior change); GovernedAgent gets a stable session id (G) and reuses the collision-safe domains helpers (H-sdk); GovernedData classifies ingested content, not the source locator (J).

**Behavior-change ledger (append to 0.10.0-changelog-notes.md):** `GovernedModel.ask()` now runs the injection firewall on the prompt and pluggable guards by default (was PII-only) and can return `action="BLOCK"`; `GovernedResponse` gains an `action` field. `GovernedAgent` now keeps a stable per-instance session so loop detection works across calls, runs loop→firewall (canonical order), and redacts non-dict upstream results. `GovernedData.ingest()` classifies the actual ingested content (string or document collection), and no longer misclassifies an opaque source locator (Path/URL) as content.
