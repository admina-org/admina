# 0.10.0 Plan 08 — Configurable Retry / Backoff on the Governed Primitives

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add an opt-in, configurable retry/backoff policy to the three governed SDK primitives (GovernedModel, GovernedAgent, GovernedData), wrapping only the upstream call, with a default-deny retryability contract and no new runtime dependency; and retrofit the blocking adapter calls with `asyncio.to_thread` so per-attempt timeouts can actually fire.

**Architecture:** A vendored `RetryPolicy` dataclass + `run_with_retry(coro_factory, policy, classify)` async executor in `admina/sdk/retry.py` (~40 LOC, no tenacity — tenacity is not a runtime dep). Marker exceptions `RetryableUpstreamError`/`TerminalUpstreamError` in `admina/sdk/errors.py` let third-party adapters opt in/out. Each primitive gains `retry: RetryPolicy | None = None`; `None` = single attempt (behaviour identical to today). Only the upstream await is wrapped (PII redaction + event emission stay outside the retried region, run once). The classifier is **default-deny**: governance refusals (`PermissionError`, BLOCK/CIRCUIT_BREAK return values) and unknown exceptions are NOT retried; only transient transport errors are.

**Tech Stack:** Python 3.11, pytest (`.venv/bin/python -m pytest`). No new deps. Branch `release/0.10.0`. Commit per task; NEVER tag; do not push.

**Roadmap item:** ROADMAP 0.10 "SDK: configurable retry / backoff policies on all governed primitives".

**Streaming note:** retry is confined to the single request/response. The "no retry once a stream has started" rule is reserved for the 0.11 streaming work and documented as a known constraint (no streaming exists in 0.10).

```python
# Apache header
"""Vendored retry/backoff executor for the governed SDK primitives.

No third-party dependency (tenacity is not a runtime dep). Default-deny
retryability: only transient transport errors are retried; governance
refusals and unknown errors are terminal.
"""
from __future__ import annotations

import asyncio
import os
import random
import time
from collections.abc import Awaitable, Callable
from dataclasses import dataclass
from typing import Any

from admina.sdk.errors import RetryableUpstreamError, TerminalUpstreamError

# Exception type-NAME hints for common provider transient errors (httpx, openai,
# botocore) — matched by name so the SDK does not import those optional deps.
_TRANSIENT_NAMES = frozenset({
    "TimeoutException", "ConnectTimeout", "ReadTimeout", "ConnectError",
    "APITimeoutError", "APIConnectionError", "RateLimitError",
    "InternalServerError", "ServiceUnavailableError", "ThrottlingException",
})


def _default_retryable(exc: BaseException) -> bool:
    """Default-deny classifier: True only for clearly-transient transport errors."""
    if isinstance(exc, TerminalUpstreamError):
        return False
    if isinstance(exc, RetryableUpstreamError):
        return True
    if isinstance(exc, (asyncio.TimeoutError, TimeoutError, ConnectionError)):
        return True
    # name-based hint for optional-dep provider errors (not imported)
    if type(exc).__name__ in _TRANSIENT_NAMES:
        return True
    # HTTP status hint (httpx/requests-style): retry 429 + 5xx
    status = getattr(getattr(exc, "response", None), "status_code", None)
    if isinstance(status, int) and (status == 429 or 500 <= status < 600):
        return True
    return False  # default-deny: PermissionError, ValueError, etc. are terminal


@dataclass
class RetryPolicy:
    max_attempts: int = 3
    base_delay_s: float = 0.2
    max_delay_s: float = 10.0
    jitter: str = "full"          # "none" | "full" | "equal"
    timeout_s: float | None = None  # per-attempt timeout (asyncio.wait_for)
    retry_on: Callable[[BaseException], bool] | None = None

    @classmethod
    def from_env(cls) -> RetryPolicy:
        """Build from ADMINA_RETRY_* env vars (sane defaults if unset)."""
        return cls(
            max_attempts=int(os.environ.get("ADMINA_RETRY_MAX_ATTEMPTS", "3")),
            base_delay_s=float(os.environ.get("ADMINA_RETRY_BASE_DELAY_S", "0.2")),
            max_delay_s=float(os.environ.get("ADMINA_RETRY_MAX_DELAY_S", "10.0")),
            jitter=os.environ.get("ADMINA_RETRY_JITTER", "full"),
        )

    def _delay(self, attempt: int) -> float:
        raw = min(self.max_delay_s, self.base_delay_s * (2 ** (attempt - 1)))
        if self.jitter == "full":
            return random.uniform(0, raw)  # noqa: S311 — backoff jitter, not crypto
        if self.jitter == "equal":
            return raw / 2 + random.uniform(0, raw / 2)  # noqa: S311
        return raw


async def run_with_retry(
    coro_factory: Callable[[], Awaitable[Any]],
    policy: RetryPolicy | None,
    classify: Callable[[BaseException], bool] | None = None,
) -> Any:
    """Run coro_factory() with retry/backoff per *policy*.

    coro_factory is a no-arg callable returning a FRESH awaitable each call (a
    coroutine cannot be re-awaited). policy=None → exactly one attempt.
    """
    if policy is None:
        return await coro_factory()
    is_retryable = policy.retry_on or classify or _default_retryable
    last_exc: BaseException | None = None
    for attempt in range(1, policy.max_attempts + 1):
        try:
            aw = coro_factory()
            if policy.timeout_s is not None:
                return await asyncio.wait_for(aw, timeout=policy.timeout_s)
            return await aw
        except BaseException as exc:  # noqa: BLE001 — re-raised below if terminal
            last_exc = exc
            if attempt >= policy.max_attempts or not is_retryable(exc):
                raise
            await asyncio.sleep(policy._delay(attempt))
    assert last_exc is not None
    raise last_exc
```

(Note: `asyncio.wait_for` raises `asyncio.TimeoutError` which IS classified retryable, so a per-attempt timeout retries until max_attempts — correct. If `timeout_s` with `max_attempts=1`, the timeout propagates, as the test expects.)

def test_openai_send_offloads_blocking_call(monkeypatch):

    from admina.plugins.builtin.adapters.openai import OpenAIAdapter
    a = OpenAIAdapter(api_key="k", default_model="gpt-x")
    # fake client returns a usable response
    mock_choice = type("C", (), {"message": type("M", (), {"content": "hi"})()})()
    mock_resp = type("R", (), {"choices": [mock_choice], "usage": type("U", (), {"total_tokens": 4})()})()

        seen["to_thread"] += 1
        return await real(fn, *args, **kw)

    assert out["text"] == "hi"
    assert seen["to_thread"] == 1   # the blocking create() was offloaded

## Self-review notes

- **Wrap only the upstream await** — PII redaction, the run_pipeline request leg, residency checks, and event emission run ONCE (outside the retried region). Each retry re-sends the same already-redacted input. This is the whole point of the tight wrap.
- **Default-deny classifier** — governance refusals (`PermissionError`, BLOCK/CIRCUIT_BREAK return values) are never retried. Provider transient errors are matched by marker exception, stdlib type, name hint, or HTTP status — without importing httpx/openai/botocore (SDK stays dependency-light).
- **retry=None default** — every existing caller behaves identically (single attempt). Retry is strictly opt-in.
- **GovernedAgent idempotency** — opt-in is the safety: a non-idempotent tool call (payment, git_push) is not silently retried unless the caller sets a policy.
- **to_thread retrofit** (Task 2) closes the pre-existing openai/ollama event-loop-blocking flagged in the Plan-07 adapter review, and is a prerequisite for `timeout_s` to fire against those adapters.
- **Streaming** — no streaming in 0.10; the "no retry once a stream starts" rule is reserved for 0.11 and noted.
- **Audit findings closed:** ollama.py / openai.py blocking-sync-in-async (HIGH) via the to_thread retrofit; alerts/webhook blocking urlopen (HIGH) is a separate alert-channel path — note it as a follow-up if not in scope here (it is NOT a governed-primitive call site; track it for a later patch).
