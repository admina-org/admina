### Task 1: EU AI Act gap analysis pads declared checks to the canonical count (HIGH)

`eu_ai_act.py` `gap_analysis` does `checks = current_compliance.get(req_key, [False]*len(req_info["checks"]))` then `zip(req_info["checks"], checks)`. `zip` truncates to the shorter list, so a 1-element `checks` (from a bool, or a short list) against a 4-check requirement evaluates only 1 of 4 — `{key: True for all 7 reqs}` yields 7/7 = 100% COMPLIANT with 21/28 checks unassessed. `nis2.py:206-208` already pads/truncates correctly; mirror it. Also `ComplianceKit.generate_report` passes raw `current_compliance` (with bools) straight to the engine, so the engine must coerce bools too (a bare bool zipped against a list raises TypeError).

```python
def _coerce_checks(value: Any, n: int) -> list[bool]:
    """Normalise a declared-compliance value to exactly *n* booleans.

    Accepts a bool (treated as that value for the FIRST check, the rest
    unmet — a single claim does not satisfy all checks), a list[bool]
    (padded with False / truncated to n), or None (all unmet). Prevents a
    short or bool input from being zip-truncated into a falsely high score.
    """
    if value is None:
        return [False] * n
    if isinstance(value, bool):
        declared = [value]
    elif isinstance(value, list):
        declared = [bool(v) for v in value]
    else:
        declared = [False]
    declared = declared[:n]
    declared += [False] * (n - len(declared))
    return declared
```

```python
def _luhn_valid(number: str) -> bool:
    """Return True if the digit string passes the Luhn checksum."""
    digits = [int(c) for c in number if c.isdigit()]
    if len(digits) < 13:  # shortest valid PAN
        return False
    checksum = 0
    parity = len(digits) % 2
    for i, d in enumerate(digits):
        if i % 2 == parity:
            d *= 2
            if d > 9:
                d -= 9
        checksum += d
    return checksum % 10 == 0
```

```python
    @staticmethod
    def _resolve_overlaps(matches: list[dict]) -> list[dict]:
        """Merge overlapping spans into non-overlapping ones.

        Sorted by (start, -length); a match overlapping the last kept span is
        dropped (the first/longer span wins) so redaction can never corrupt
        text or leave a fragment from a partially-overlapping detection.
        """
        if not matches:
            return matches
        ordered = sorted(matches, key=lambda m: (m["start"], -(m["end"] - m["start"])))
        kept: list[dict] = []
        for m in ordered:
            if kept and m["start"] < kept[-1]["end"]:
                # overlaps the last kept span — extend its end if this one
                # reaches further so the union is fully covered, then drop it
                if m["end"] > kept[-1]["end"]:
                    kept[-1] = {**kept[-1], "end": m["end"], "text": None}
                continue
            kept.append(m)
        return kept
```
