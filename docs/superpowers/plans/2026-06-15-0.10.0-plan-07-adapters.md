# 0.10.0 Plan 07 — Model Adapters (Anthropic, Mistral, Bedrock, Gemini, vLLM)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship native model adapters for Anthropic, Mistral, AWS Bedrock, and Google Gemini, plus a vLLM convenience adapter, each a builtin `BaseModelAdapter` plugin auto-discovered by the registry; wire per-provider + roll-up + `all` extras.

**Architecture:** Each adapter subclasses `BaseModelAdapter` (`admina/plugins/base.py`), follows the established `openai.py` pattern (class-attr `name`, lazy SDK import with an actionable `ImportError` naming the extra, normalize the response to `{"text", "metadata": {"tokens", "latency_ms", "model"}}`), and is registered under its `name` (Phase-0 registry fix). The blocking provider SDK call runs inside `asyncio.to_thread(...)` so it never blocks the event loop (required for boto3, applied uniformly). vLLM is a thin subclass of `OpenAIAdapter` (vLLM serves an OpenAI-compatible API). **No model id is hardcoded** — each adapter takes the model via a per-call `model=` kwarg or an `ADMINA_<PROVIDER>_MODEL` env var, raising a clear error if neither is set (per the project rule against hardcoding Claude/provider model ids from memory).

**Tech Stack:** Python 3.11, pytest (`.venv/bin/python -m pytest`). New optional deps: `anthropic`, `mistralai`, `google-genai`, `boto3` (already in `[proxy]`). Branch `release/0.10.0`. Commit per task; NEVER tag; do not push.

**Method note (per adapter):** the provider SDKs are optional and may not be installed. Each adapter task **installs the SDK into the venv** (`.venv/bin/python -m pip install <sdk>`) and **inspects the real API** (signatures, response object attributes) before writing the adapter — do NOT write SDK calls from memory. Tests use the existing mock-`_client` pattern (inject a fake client, assert the request shaping + response normalization) guarded by `pytest.importorskip("<sdk>")`, so they run in CI (which installs `--all-extras`) and skip locally when the SDK is absent.

**Roadmap item:** ROADMAP 0.10 "Model adapters: Anthropic, Mistral, AWS Bedrock, Google Gemini, native vLLM".

```python
from admina.plugins.builtin.adapters.openai import OpenAIAdapter

class VLLMAdapter(OpenAIAdapter):
    """vLLM serves an OpenAI-compatible API; reuse OpenAIAdapter with vLLM defaults."""
    name = "vllm"
    def __init__(self, api_key=None, base_url=None, default_model=None):
        super().__init__(
            api_key=api_key or os.environ.get("ADMINA_VLLM_API_KEY", "EMPTY"),
            base_url=base_url or os.environ.get("ADMINA_VLLM_BASE_URL", "http://localhost:8000/v1"),
            default_model=default_model or os.environ.get("ADMINA_VLLM_MODEL"),
        )
    def supports_model(self, model_name: str) -> bool:
        return True  # vLLM serves arbitrary HF model ids
```

## Self-review notes

- **No hardcoded model ids** — each cloud adapter requires `model=`/`ADMINA_<PROVIDER>_MODEL` and raises a clear error otherwise. This satisfies the project rule (no Claude/provider model ids from memory) and avoids stale defaults; the trade-off (less "ready to use") is acceptable for model selection, which is deployment-specific. vLLM always gets `model=` from the caller (arbitrary HF id).
- **asyncio.to_thread uniformly** — all new adapters offload the blocking sync SDK call so the event loop is never blocked (mandatory for boto3; correct for the sync anthropic/mistral/gemini clients too). The existing openai/ollama adapters call blocking clients directly; retrofitting them with to_thread is the retry plan's job (noted, not done here).
- **No `select_adapter` routing helper** (decided in brainstorm) — adapters are selected explicitly by the caller; `supports_model` is implemented for a future selector.
- **ABC unchanged** (3 methods) — no streaming surface; that lands in 0.11.
- **CI runs `--all-extras`** so the `importorskip`-guarded adapter tests run for real in CI; locally they skip when a provider SDK is absent. The install-and-inspect step per task guards against writing wrong SDK calls from memory.
- The `[all]` extra references `[presidio]` — coordinate with the Presidio plan (add presidio to `[all]` when that extra exists; until then `[all]` omits it).
